# Portafolio

Proyectos web inspirados en moda, streetwear y música.

| # | Proyecto | Descripción |
|---|----------|-------------|
| 01 | [Bearysad](proyectos/bearysad/) | Tienda de ropa para la marca chilena Bearysad: catálogo con filtros, talla, color y cantidad; carrito con envío gratis y códigos de descuento (`BEARY10`, `ICONS15`); checkout simulado en 3 pasos; y **Beary Icons**, un escenario interactivo con biografía, preview de 30 s de cada artista con visualizador de audio, y "arma el fit". |

## Cómo verlo
Es HTML, CSS y JavaScript puro, sin dependencias. Abre `index.html` o sirve la carpeta:

```bash
python -m http.server 5173
```

Fotos de campaña “Summertime & Icecream” en `assets/campaign`. Previews de audio vía iTunes Search API.

Imágenes y contenido de la marca © Bearysad ([bearysad.com](https://bearysad.com)).
