# Portafolio

Proyectos web inspirados en moda, streetwear y música.

| # | Proyecto | Descripción |
|---|----------|-------------|
| 01 | [Bearysad](proyectos/bearysad/) | Tienda de ropa para la marca chilena Bearysad: catálogo con filtros, selección de talla y color, carrito y sección **Beary Icons** con una página personalizada por artista. |

## Cómo verlo
Es HTML, CSS y JavaScript puro, sin dependencias. Abre `index.html` o sirve la carpeta:

```bash
python -m http.server 5173
```

Imágenes y contenido de la marca © Bearysad ([bearysad.com](https://bearysad.com)).
